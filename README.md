# Monster & BUGANi Sales Pocket

คู่มือเรียนสินค้าสำหรับพนักงานหน้าร้าน — แบรนด์ Monster และ BUGANi ของ YAS
เปิดจากมือถือได้ทันที ไม่ต้องติดตั้ง ไม่ต้องล็อกอิน

**เปิดใช้งาน:** https://vitchayaclaude.github.io/monster-bugani-sales-pocket/

## มีอะไรบ้าง

- **18 รุ่น / 33 SKU** แบ่ง 4 หมวด — Monster หูฟังไร้สาย, Monster หูฟังครอบหู, Monster ลำโพง, BUGANi ลำโพง
- แต่ละรุ่นมี **Story Telling** (เรื่องเล่าเปิดการขาย), **จุดขายหลัก**, **ประโยคปิดการขาย**, ราคา SRP, ตาราง SKU/บาร์โค้ดแยกสี และสเปกเครื่อง
- **รูปสินค้าจริงทุกสี** ฝังอยู่ในไฟล์ ใช้งานออฟไลน์ได้
- **แบบทดสอบ 3 ชุด ชุดละ 20 ข้อ** สุ่มคำถามและตัวเลือกใหม่ทุกครั้ง เกณฑ์ผ่าน 16/20
- จัดหน้าสำหรับ iPhone โดยเฉพาะ — แท็บล่างจอ เผื่อ safe area ช่องค้นหาไม่ทำให้จอซูม

## ที่มาของข้อมูล

สร้างจาก `ProductMaster_YAS.xlsx` — ราคาที่แสดงคือ **SRP เท่านั้น** ไม่มีต้นทุน GP หรือราคาดีลเลอร์อยู่ในไฟล์นี้

ส่วนที่เพิ่มเข้ามานอกเหนือจาก Product Master: Story Telling, ประโยคปิดการขาย และคำแปลไทยของ Key Selling Point ฝั่ง BUGANi

## เรื่องที่ควรแก้ที่ Product Master

1. คอลัมน์ **Ecommerce** มีค่าเท่ากับ COGS (incl.VAT) ทุกแถว ไม่ใช่ราคาขายออนไลน์
2. **Clarity 200 ANC** มีสเปกและ KSP ซ้ำกับ N-Lite 206 และไม่มีค่าความลึก ANC ระบุไว้
3. **Persona 5th ANC** และ **Mission 350** ถูกใส่หมวดเป็น TWS Earphone แต่ตัวสินค้าจริงเป็นหูฟังครอบหู
4. **Brief TT** ราคาสูงกว่า **Brief** แต่กำลังขับต่ำกว่า (6W เทียบ 28W พีค)

## แก้ไขเนื้อหา

`index.html` เป็นไฟล์เดียวจบ รวม HTML, CSS, JS, ข้อมูลสินค้า, รูปภาพ และคลังคำถามไว้ทั้งหมด
แก้แล้ว commit ขึ้น `main` เว็บจะอัปเดตเองภายในไม่กี่นาที
